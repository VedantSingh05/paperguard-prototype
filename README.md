# PaperGuard – Prototype

Clickable front-end prototype of **PaperGuard**, a secure question paper distribution and verification system for examination centres.

Built for Experiment 5 (Community Engagement Project), Don Bosco Institute of Technology.

## Screen flow
1. Centre sign-in
2. Papers for your centre (dashboard)
3. Verify paper (hash, signature, centre, release time, revocation)
4. Review print job (copies, batch QR preview)
5. Print recorded (confirmation)

## Run it
Open `index.html` in any browser. No installation needed.

## Tech
HTML, CSS and JavaScript (single file, no libraries).

## Note
This is a UI prototype. All data (paper IDs, hashes, QR code) is dummy. No real question papers are used.
